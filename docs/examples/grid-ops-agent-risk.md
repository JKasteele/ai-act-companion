**Description.** An LLM-based agent that monitors electricity-grid telemetry, diagnoses anomalies and can autonomously execute remediation actions (rerouting load, restarting controllers) through backend APIs, under on-call engineer oversight.

**Intended purpose.** Assist and partly automate the safe operation of a regional electricity distribution grid.
